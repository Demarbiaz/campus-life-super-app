# Campus Life Super App

## Project Description
Campus Life Super App is a website designed to make college life easier for students. It puts helpful campus information in one place so students can stay organized and find resources.

## Purpose
The purpose of this project is to help college students keep track of their schedules, assignments, campus resources, and announcements.

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap 5
- JSONPlaceholder API
- GitHub Pages

## Website Pages
- **Home:** Shows campus announcements, updates, and quick links.
- **Schedule:** Shows a sample class schedule and assignment checklist.
- **Campus:** Shows campus resources such as dining, the library, and activities.

## Features
- Navigation between three different pages.
- Responsive design using Bootstrap and custom CSS.
- Announcement button with JavaScript.
- External API that displays sample information.
- Assignment checklist.
- Campus resource information.

## How to Use
1. Open the home page.
2. Use the navigation links to visit the other pages.
3. Visit the schedule page to view the class schedule and assignment checklist.
4. Visit the campus page to explore campus resources.
5. Use the announcement button to see a message.

## Setup Instructions
1. Download or clone this GitHub repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Make sure you have an internet connection for Bootstrap and the API.

## Deployment
This project is deployed using GitHub Pages.

To deploy:
1. Open the repository on GitHub.
2. Go to Settings.
3. Select Pages.
4. Choose the main branch.
5. Select the root folder and save.
