
# Campus Life Super App

This website is designed to make college life easier for students.

## Pages
- Home: Campus announcements and updates.
- Schedule: Class schedules and assignment reminders.
- Campus: Dining, library, and student activities.

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- API integration

## Purpose
The goal of this project is to help college students stay organized and find useful campus information.
